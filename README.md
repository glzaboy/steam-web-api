# Steam Sda Web API

Steam Sda 的官方网站与管理后台。为 **Steam Sda** 桌面端 / 命令行工具的用户提供网页端入口，可以在浏览器里管理账号、订阅与浏览游戏库。

## 这个网站能做什么

- **微软账号登录**：使用微软账号一键授权登录，自动同步昵称与已购订阅，无需单独注册。
- **产品与订阅管理**：查看全部可订阅的产品，管理当前账号已开通的订阅，支持一键开通。
- **游戏库浏览**：按「分类」「平台」浏览游戏，查看游戏详情与玩家评论，列表支持分页翻页。
- **机器码绑定**（可选）：桌面端 / 命令行工具可将设备与账号绑定，提升账号安全性。
- **明暗主题**：界面跟随系统自动切换浅色 / 深色。

## 账号与登录

点击页面右上角的「登录」，使用微软账号完成授权即可。

桌面端用户也可直接在 Steam Sda 客户端内打开本网站——客户端会自动携带登录态，无需再次授权。
