# 环境配置

本文档说明在本地搭建 `steam-web-api` 开发环境所需的依赖与环境变量。

---

## 1. 环境要求

- **Node.js 20+**（建议 22 LTS；项目使用 Next.js 16 + Turbopack，要求较新 Node）。
- `wrangler@^4`（随项目依赖安装，用于本地 D1 与部署）。
- 一个 Cloudflare 账号，且对 D1 数据库 `steamsda-api` 有访问权限。

---

## 2. 安装依赖

```bash
npm install
```

> 验证 wrangler 可用：`npx wrangler --version`

---

## 3. 环境变量

项目使用两类变量，对应两套机制，**不能混用**：

### 3.1 浏览器端公开配置（必须以 `NEXT_PUBLIC_` 前缀）

这类变量在 **构建时** 就被 Next.js 内联进客户端 bundle，浏览器端代码（如 MSAL 登录）才能读到。修改后必须重新构建 / 部署。

| 变量 | 说明 |
| :--- | :--- |
| `NEXT_PUBLIC_MICROSOFT_CLIENT_ID` | 与 steamsda 桌面端共用的 Azure 应用（SPA）Client ID |
| `NEXT_PUBLIC_REDIRECT_URI` | 微软回跳地址。本地 `http://localhost:3000`；线上 `https://steamsda.com` |

- 本地开发专用覆盖放在 `.env.development.local`：
  ```bash
  # .env.development.local
  NEXT_PUBLIC_REDIRECT_URI=http://localhost:3000
  ```
  该文件仅 `npm run dev` 生效，且已被 `.gitignore` 忽略，不会进仓库。

### 3.2 服务端密钥（运行时读取，不进客户端 bundle）

`AUTH_SECRET`、`RESEND_API_KEY` 等服务端密钥通过 `wrangler.jsonc` 的 `vars` 或 `wrangler secret put` 注入；本地 dev 由 miniflare/wrangler 提供。

此外，drizzle-kit 直连线上 D1 需要以下变量（放在 `.env`，本地使用）：

| 变量 | 说明 |
| :--- | :--- |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare 账号 ID |
| `CLOUDFLARE_DATABASE_ID` | D1 数据库 ID |
| `CLOUDFLARE_D1_TOKEN` | 具备 D1 权限的 API Token |

> ⚠️ 敏感信息（D1 Token、AUTH_SECRET、RESEND_API_KEY）切勿明文提交到仓库；线上请使用 `wrangler secret put` 管理。
